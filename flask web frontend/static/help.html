How to use

1. Enter observations and click away from the input to look them up. You can mix iNaturalist and Mushroom Observer entries.

Supported input formats:

  • iNaturalist: Enter just the number (e.g., 150291663) or the full observation URL to generate an iNaturalist label.
  • Mushroom Observer: Enter MO12345 (case-insensitive) or a Mushroom Observer observation URL to generate a Mushroom Observer label.
  • Convert MO → iNat: Enter motoinat12345 to convert the MO observation to its iNaturalist counterpart and generate an iNaturalist label.
  • BugGuide: Enter BG12345, BG 12345, or BugGuide 12345. Only supported when generating minilabels.

2. You can also enter multiple numbers separated by a space or comma.

3. You'll receive immediate feedback with the organism name and the iNaturalist / MO user who created the observation.

Printing labels

You can make labels for 500 observations at a time. If you want more, contact Alan Rockefeller or use the command line tool. When you're ready:

1. Click Print PDF Labels to download labels.pdf, or Print RTF Labels to download labels.rtf.

2. Open the RTF file in LibreOffice Writer or Microsoft Word; open the PDF in any PDF viewer or web browser. LibreOffice Writer works better than MS Word because MS Word doesn't wrap the labels properly, so some will be split between pages, requiring manual editing.

3. The labels will be arranged in two columns with QR codes. Often 8 labels fit on a page - but that depends on your observation fields.

Note (RTF): If the QR code is missing, ensure you're opening the RTF file in a program that supports images in RTF files like Libreoffice Writer.

Add observations in bulk

Instead of pasting observations one at a time, + Add many at once finds every observation matching an observer, a date range, and optionally a taxon, and queues them together. It is useful after a field day, a trip, or a batch of recent uploads.

1. On the trailing empty observation row, click + Add many at once to the right of the ID input, then choose iNaturalist or Mushroom Observer.

2. Enter the observer's username and a date range. The date presets make recent sessions especially quick; add a taxon if you want to narrow the search.

3. Results appear automatically. Review the organisms, filter or sort the list, then select individual observations or use Select all.

4. Click Add observations. The selected records are added to the main page together, ready to print.

For iNaturalist searches, you can switch between the date an observation was observed and the date it was created.

Require observation field (iNaturalist only): Start typing an observation field name and choose it from the suggestions. The results will include only observations where that field has a nonempty value. This is useful for finding records with data such as a personal voucher number, herbarium accession number, or DNA barcode. It filters which observations are added; it does not control which fields are printed on the labels.

One-click URL preloading

You can preload observations and label options directly in the URL. This is useful for sharing a link that opens the label generator with the observation list and print settings already filled in.

Common URL parameters:

  • obs, observations, or ids: observation numbers, separated by commas. Repeating the parameter also works.
  • omit_qr_codes=1: check Omit QR Codes.
  • print_duplicate_labels=1: check Print duplicate labels.
  • minilabel_size=1 through minilabel_size=10: enable Mini-labels at that size.
  • common_names=1 and omit_notes=1: check those label options.
  • sort=date, sort=date-desc, sort=voucher, or sort=none: set the label sort order. Use sort=custom&sort_field=Field%20Name to sort by a named label field. Omit the parameter for the default observation-number order.
  • add_fields and remove_fields: include or exclude observation fields. Separate multiple fields with commas.
  • open_add_observations=1 with source, username, taxon, d1, and d2: open the + Add many at once panel from the trailing empty observation row with those filters prefilled.

Clickable examples:

BugGuide labels

You can create labels for BugGuide observations by entering the BugGuide ID directly into the input fields using formats such as BG 2520730, BG2520730, or BugGuide 2520730.

Important note: BugGuide inputs are only supported when the Mini-labels option is enabled. If you enter BugGuide IDs during a normal label print run, they will be skipped.
